# No reference solution for alg01 — on purpose

The compulsory exercise **Algorithms number 1** (due 4 September) asks you to
implement Boyer-Moore and both versions of longest-common-subsequence in
Python. Those are exercises 3, 11 and 12 of this week.

Shipping worked code for them two days before the deadline would be handing you
the assignment, so this folder holds no `exercises.py`. The 76 checks in
`../../alg01/tests.py` are your feedback loop instead — they tell you when your
implementation is right without telling you what to write.

The tests were verified against a working implementation before it was
discarded, so if a check disagrees with you, the check is very likely correct.

The paper answers in `PAPER.md` **are** here — they cover the concepts, not the
assignment's problems.

Ask me for a reference solution after the deadline and I will write one.
